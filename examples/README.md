# Приклади робіт PyPaint

У цій папці зібрано кілька простих прикладів, які демонструють типові сценарії роботи в редакторі.

## Вміст

- `example_1_house.png` — базова композиція з ліній, прямокутників та еліпсів. Показує, як поєднувати геометричні інструменти в одному малюнку.
- `example_2_landscape.png` — пейзаж з простими фігурами. Демонструє роботу з фоном, кольорами та великими областями полотна.
- `example_3_eraser_demo.png` — невелика сцена з контрастними елементами. Підходить для показу стирачки та подальшого редагування.

## Як використати на захисті

- Відкрити редактор і відтворити окремі елементи з прикладів вручну.
- Показати, як змінюється фон для всього полотна.
- Продемонструвати `Undo/Redo` після додавання ліній або зміни фону.
- Показати довідку з меню `Довідка`, не виходячи із застосунку.
