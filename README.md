# PyPaint — Системний Графічний Редактор

**PyPaint** — це сучасний графічний редактор, розроблений як повна системна програма на мові Python з використанням фреймворку PyQt6. Програма створена з акцентом на ергономіку, зручність користувача та надійність.

## 🌟 Основні можливості

*   **Набір інструментів малювання:** Олівець (вільне малювання), Пряма лінія, Прямокутник та Еліпс.
*   **Гнучке налаштування стилю:** Вибір будь-якого кольору через системну палітру та регулювання товщини ліній.
*   **Інтелектуальна історія дій:** Повна підтримка скасування (**Undo**) та повторення (**Redo**) дій за допомогою виділених кнопок на панелі інструментів.
*   **Керування файлами:** Створення нових полотен та збереження робіт у форматах **PNG** або **JPG**.
*   **Ергономічний інтерфейс:**
    *   Групування інструментів у функціональні панелі (Toolbars).
    *   Можливість приховувати/показувати окремі групи інструментів.
    *   Україномовний інтерфейс та зрозумілі підказки (Tooltips).
*   **Захист від помилок:** Діалоги підтвердження при очищенні полотна або виході без збереження.
*   **Вбудована довідка:** Доступ до інструкцій безпосередньо з меню програми.

## 🛠 Інструкція з інсталяції

1.  **Переконайтеся, що встановлено Python 3.10+**.
2.  **Створіть віртуальне середовище** (рекомендовано):
    ```bash
    python -m venv .venv
    ```
3.  **Активуйте віртуальне середовище**:
    *   Windows: `.venv\Scripts\activate`
    *   Linux/macOS: `source .venv/bin/activate`
4.  **Встановіть необхідну бібліотеку**:
    ```bash
    pip install PyQt6
    ```

## 🚀 Як користуватися програмою

### Запуск
Виконайте команду у терміналі:
```bash
python main.py
```

### Малювання
1.  Оберіть потрібний інструмент на панелі **"Інструменти малювання"** (наприклад, ✏️ Олівець або ⬜ Прямокутник).
2.  На панелі **"Властивості"** натисніть 🎨 Колір, щоб обрати відтінок, та встановіть товщину лінії.
3.  Натисніть ліву кнопку миші на полотні та ведіть її, щоб почати малювання.

### Скасування помилок
Якщо ви припустилися помилки, натисніть кнопку **↩️ Скасувати** на панелі **"Історія дій"**. Ви також можете повернути скасовану дію кнопкою **↪️ Повторити**.

### Робота з файлами
*   Щоб зберегти роботу, натисніть **💾 Зберегти** або виберіть у меню **Файл -> Зберегти як...**.
*   Для створення нового малюнку натисніть **📄 Новий**. Програма запитає підтвердження, якщо у вас є незбережені зміни.

### Налаштування вигляду
Ви можете приховати панелі, якими не користуєтеся, через меню **"Вигляд"**. Наприклад, якщо вам потрібно більше місця, вимкніть панель "Файлові операції".
